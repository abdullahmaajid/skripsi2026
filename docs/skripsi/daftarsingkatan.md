**DAFTAR SINGKATAN**

**A**
**ACID**
Atomicity, Consistency, Isolation, Durability, sekumpulan sifat untuk menjamin keandalan transaksi sistem basis data.
**AI**
Artificial Intelligence, teknologi kecerdasan buatan yang digunakan untuk menjalankan fungsi pemrosesan dan pemberian respons secara otomatis.
**API**
Application Programming Interface, mekanisme yang memungkinkan sistem berkomunikasi dan bertukar data dengan layanan atau aplikasi lain.

**B**
**BPPP**
Balai Pengelolaan Pengujian Pendidikan, lembaga yang bertanggung jawab mengelola pengujian pendidikan nasional di Indonesia.

**C**
**CBT**
Computer-Based Test, sistem pelaksanaan evaluasi dan ujian menggunakan perangkat komputer.
**CLI**
Command Line Interface, antarmuka berbasis baris perintah yang digunakan untuk menjalankan perintah pada sistem operasi.
**CLT**
Cognitive Load Theory, teori beban kognitif yang memfokuskan pada batasan kapasitas memori kerja manusia dalam memproses informasi.
**CORS**
Cross-Origin Resource Sharing, mekanisme keamanan yang mengatur permintaan sumber daya dari domain yang berbeda.
**CSP**
Content Security Policy, mekanisme keamanan untuk mengatur dan membatasi sumber daya yang diizinkan berjalan pada aplikasi web.
**CTT**
Classical Test Theory, teori tes klasik yang menggunakan skor mentah (persentase) dalam pengukuran evaluasi hasil belajar.

**D**
**DAST**
Dynamic Application Security Testing, metode pengujian keamanan perangkat lunak dengan mengeksekusi dan menyerang aplikasi secara langsung dari luar.
**DOM**
Document Object Model, representasi hierarki struktur dokumen HTML pada peramban web.

**E**
**ERD**
Entity Relationship Diagram, rancangan visual basis data yang menggambarkan entitas dan hubungan antarentitas dalam sistem.

**H**
**HMR**
Hot Module Replacement, mekanisme pembaruan modul kerangka kerja web saat aplikasi berjalan tanpa perlu menyegarkan halaman secara penuh.
**HOTS**
Higher Order Thinking Skills, keterampilan berpikir tingkat tinggi yang mencakup tahapan analisis, evaluasi, dan kreasi.
**HTML**
Hypertext Markup Language, bahasa markah standar yang digunakan untuk membuat struktur halaman web.
**HTTP**
Hypertext Transfer Protocol, protokol komunikasi yang digunakan dalam pertukaran data antara klien dan peladen melalui jaringan.

**I**
**IRT**
Item Response Theory, paradigma pengukuran psikometri probabilistik yang memodelkan interaksi antara kemampuan peserta dan karakteristik butir soal.
**ITS**
Intelligent Tutoring System, sistem pembelajaran berbantuan komputer yang memberikan pendampingan, instruksi, dan umpan balik secara adaptif.

**J**
**JSON**
JavaScript Object Notation, format standar pertukaran data yang ringan dan mudah dibaca oleh manusia maupun mesin.

**L**
**LLM**
Large Language Model, model kecerdasan buatan berbasis *deep learning* yang mampu memahami, memproses, dan menghasilkan teks berdasarkan masukan.

**M**
**MLE**
Maximum Likelihood Estimation, metode statistika komputasi numerik yang digunakan untuk mengestimasi titik temu (*konvergen*) dalam pemodelan probabilitas.

**O**
**ORM**
Object-Relational Mapping, teknik yang menjembatani basis data relasional ke dalam konsep paradigma pemrograman berorientasi objek.
**OWASP**
Open Worldwide Application Security Project, organisasi nirlaba yang menyediakan standar, panduan, dan sumber daya terkait keamanan aplikasi web.

**P**
**PTN**
Perguruan Tinggi Negeri, institusi pendidikan tinggi yang diselenggarakan secara resmi oleh pemerintah di Indonesia.

**R**
**RBAC**
Role-Based Access Control, mekanisme pengendalian hak akses berdasarkan otoritas dan peran pengguna di dalam sistem.
**RDBMS**
Relational Database Management System, sistem manajemen pangkalan data yang mendasarkan pengorganisasian strukturnya pada relasi tabel.
**REST**
Representational State Transfer, pola arsitektur perangkat lunak untuk komunikasi web berbasis API yang terstandarisasi.

**S**
**SAW**
Simple Additive Weighting, metode pengambilan keputusan komputasi berbasis penjumlahan nilai terbobot.
**SMA**
Sekolah Menengah Atas, jenjang pendidikan menengah umum formal di Indonesia.
**SMK**
Sekolah Menengah Kejuruan, jenjang pendidikan menengah kejuruan dan vokasi di Indonesia.
**SNBP**
Seleksi Nasional Berdasarkan Prestasi, jalur seleksi penerimaan mahasiswa baru perguruan tinggi negeri berbasis nilai rapor.
**SNBT**
Seleksi Nasional Berdasarkan Tes, jalur seleksi penerimaan mahasiswa baru perguruan tinggi negeri berskala nasional menggunakan ujian tulis.
**SNPMB**
Seleksi Nasional Penerimaan Mahasiswa Baru, panitia pengelola sistem seleksi penerimaan mahasiswa baru nasional di Indonesia.
**SPA**
Single Page Application, arsitektur aplikasi web modern di mana pembaruan konten dilakukan secara dinamis di klien tanpa penyegaran (*reload*) halaman penuh.
**SQL**
Structured Query Language, bahasa standar untuk mengelola, membuat kueri, dan memanipulasi data pada basis data relasional.
**SRI**
Subresource Integrity, mekanisme kriptografi yang memastikan sumber daya eksternal yang dimuat oleh web tidak dimanipulasi oleh pihak ketiga.
**SSR**
Server-Side Rendering, mekanisme merender komponen halaman web secara utuh di sisi peladen (*server*) sebelum dikirimkan menuju peramban (*browser*).
**SUS**
System Usability Scale, metode pengukuran tingkat kebergunaan (*usability*) perangkat lunak berdasarkan kuesioner sepuluh butir penilaian.

**T**
**TKA**
Tes Kemampuan Akademik, bentuk evaluasi spesifik yang berfokus pada penguasaan kognitif disiplin ilmu akademik siswa.
**TPS**
Tes Potensi Skolastik, bentuk evaluasi spesifik yang berfokus pada pengukuran kemampuan kognitif, penalaran, dan literasi siswa.

**U**
**UI**
User Interface, tata letak antarmuka pengguna pada sistem atau aplikasi perangkat lunak yang berfungsi menjembatani interaksi manusia dengan komputer.
**UML**
Unified Modeling Language, bahasa pemodelan visual yang dimanfaatkan untuk merancang dan mendokumentasikan struktur alur perilaku sistem.
**URL**
Uniform Resource Locator, alamat terstandarisasi yang digunakan untuk mengidentifikasi keberadaan suatu sumber daya di jaringan internet.
**UTBK**
Ujian Tulis Berbasis Komputer, sistem pengerjaan ujian masuk perguruan tinggi negeri di Indonesia yang sepenuhnya dioperasikan menggunakan perangkat layar komputer.

**X**
**XSS**
Cross-Site Scripting, celah kerentanan keamanan di mana penyerang berhasil menyuntikkan kode skrip berbahaya pada halaman pengguna lain.

**Z**
**ZAP**
Zed Attack Proxy, alat pemindai keamanan aplikasi web berbasis proksi untuk mengidentifikasi potensi celah kerentanan secara dinamis.
**ZPD**
Zone of Proximal Development, konsep psikologis yang mendefinisikan batas kemampuan siswa menyelesaikan masalah mandiri dan batas jika didampingi tutor.
