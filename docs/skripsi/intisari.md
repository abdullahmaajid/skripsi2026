**INTISARI**

Ujian Tulis Berbasis Komputer - Seleksi Nasional Berdasarkan Tes (UTBK SNBT) merupakan jalur utama seleksi perguruan tinggi negeri. Dalam proses latihan, siswa membutuhkan bimbingan formatif yang dapat memberikan umpan balik secara kontekstual ketika mengalami kesulitan. Namun, platform Tryout yang tersedia umumnya masih bersifat konvensional dan berfokus pada penyajian hasil akhir atau pemberian kunci jawaban instan, sementara bantuan kecerdasan buatan belum terintegrasi secara pedagogis dengan pengerjaan soal. Penelitian ini bertujuan mengembangkan platform Tryout UTBK SNBT berbasis web dengan menerapkan *Large Language Model* (LLM) sebagai *Intelligent Tutoring System* (ITS) yang dipadukan dengan pemodelan *Item Response Theory* (IRT) dan *Chancing Engine*.

Sistem dikembangkan menggunakan *framework* Next.js dengan arsitektur *Server-Side Rendering* (SSR) dan mengintegrasikan layanan agregator OpenRouter API (Gemini, Llama, Qwen) sebagai basis LLM utama. ITS menerapkan *Prompt Builder*, *Rule-Based Strategy Selector*, *Blind Mode Architecture*, dan *Socratic Scaffolding* untuk membimbing siswa menemukan konsep pemahaman secara mandiri tanpa membocorkan jawaban akhir. Sistem juga menerapkan *Mastery Tracking*, algoritma *Learning Path* dengan mempertimbangkan *Forgetting Curve*, serta tata kelola basis data PostgreSQL yang dioptimasi oleh *connection pooling* PgBouncer. Pengujian sistem dilakukan melalui *Black-Box Testing*, evaluasi *System Usability Scale* (SUS), dan *Penetration Testing* menggunakan OWASP ZAP.

Hasil pengujian menunjukkan bahwa seluruh fungsi utama (54 *test cases*) berhasil berjalan 100% sesuai rancangan fungsional. Pengujian SUS memperoleh rata-rata skor 62,93 pada Role Siswa (kategori *Good*) dan 92,5 pada Role Admin (kategori *Best Imaginable*), dengan skor keseluruhan sebesar 67,26. Sementara itu, pengujian keamanan menggunakan OWASP ZAP tidak menemukan kerentanan tingkat *High Risk*, serta optimasi basis data terbukti mampu menangani simulasi 500 koneksi serentak tanpa *downtime*. Hasil tersebut menegaskan bahwa platform telah berhasil dikembangkan secara komprehensif sebagai ekosistem evaluasi akademik cerdas yang fungsional, andal, dan siap guna.

Kata kunci: UTBK SNBT, *Intelligent Tutoring System*, *Large Language Model*, *Item Response Theory*, *Socratic Scaffolding*.

**ABSTRACT**

The Computer-Based Written Examination - National Selection Based on Testing (UTBK SNBT) is the primary admission pathway for state universities in Indonesia. During practice sessions, students require formative guidance that provides contextual feedback when encountering difficulties. However, existing Tryout platforms are generally conventional, focusing mainly on presenting final results or instant answer keys, while artificial intelligence assistance has not been pedagogically integrated into the problem-solving process. This study aims to develop a web-based UTBK SNBT Tryout platform by implementing a Large Language Model (LLM) as an Intelligent Tutoring System (ITS), combined with Item Response Theory (IRT) modeling and a university acceptance probability calculator (Chancing Engine).

The system was developed using the Next.js framework with Server-Side Rendering (SSR) architecture, integrating the OpenRouter API aggregator (Gemini, Llama, Qwen) as the core LLM engine. The ITS implements a Prompt Builder, Rule-Based Strategy Selector, Blind Mode Architecture, and Socratic Scaffolding to guide students in discovering concepts independently without directly exposing the final answers. Furthermore, the system incorporates Mastery Tracking, Learning Path algorithms adjusted with the Forgetting Curve, and PostgreSQL relational database management optimized by PgBouncer connection pooling. System testing was conducted through Black-Box Testing, System Usability Scale (SUS) evaluation, and Penetration Testing using OWASP ZAP.

The test results indicate that all main functions (54 test cases) operate successfully at 100% functional compliance. The SUS evaluation achieved an average score of 62.93 for the Student Role (Good category) and 92.5 for the Admin Role (Best Imaginable category), with an overall score of 67.26. Meanwhile, OWASP ZAP security testing confirmed the absence of High-risk vulnerabilities, and the database optimization successfully handled 500 concurrent connection simulations without downtime. These results demonstrate that the platform has been successfully and comprehensively developed as a functional, reliable, and ready-to-use intelligent academic evaluation ecosystem.

Keywords: UTBK SNBT, Intelligent Tutoring System, Large Language Model, Item Response Theory, Socratic Scaffolding.
